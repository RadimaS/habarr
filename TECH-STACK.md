# Технологический стек HABAR

## Клиентская часть (Frontend)

### Основные технологии
- **React 18** - JavaScript библиотека для создания пользовательских интерфейсов
- **TypeScript** - типизированный JavaScript для более надежного кода
- **Vite** - современный инструмент сборки для быстрой разработки

### Маршрутизация
- **React Router DOM** - для навигации между страницами приложения

### Стилизация
- **Tailwind CSS** - утилитарный CSS фреймворк
- **PostCSS** - для обработки CSS
- **Autoprefixer** - автоматическое добавление вендорных префиксов

### UI компоненты
- **Lucide React** - библиотека иконок
- **React Hot Toast** - для отображения уведомлений

### Анимации
- **Canvas Confetti** - для создания эффекта конфетти

## Серверная часть (Backend)

### База данных
- **Supabase** - платформа на основе PostgreSQL
  - Аутентификация пользователей
  - Row Level Security (RLS)
  - Хранение данных
  - Хранение медиафайлов (аудио)

### Таблицы базы данных
- `profiles` - профили пользователей
- `dictionary_words` - словарь
- `alphabet_audio` - аудио для алфавита
- `numbers_audio` - аудио для чисел
- `greetings_audio` - аудио для приветствий
- `pronouns_audio` - аудио для местоимений
- `lessons` - уроки
- `culture_cards` - карточки культуры
- `culture_content` - контент для карточек культуры

## Инструменты разработки

### Линтинг и форматирование
- **ESLint** - для проверки кода
- **TypeScript ESLint** - правила линтинга для TypeScript

### Среда разработки
- **Node.js** - среда выполнения JavaScript
- **npm** - менеджер пакетов

## Особенности реализации

- Полностью типизированный код с использованием TypeScript
- Компонентный подход с использованием React Hooks
- Адаптивный дизайн с использованием Tailwind CSS
- Безопасная аутентификация через Supabase
- Защита данных с помощью Row Level Security
- Интерактивные элементы с анимациями
- Аудио поддержка для изучения произношения
